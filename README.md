#### Flagship: career-ops — my AI job-search command center

I run my own job search as a pipeline, the way I'd design one for a client.

- Every day it scans 330+ company career sites and job boards, filters out what doesn't fit, and scores the rest with LLMs against my profile — 3,900+ postings evaluated so far.
- For strong matches it prepares an application package: a tailored CV, a "hiring manager's read" of that CV, and the likely hiring manager.
- Daily digest and approvals in Telegram, a web panel for review, a browser extension that fills application forms; it reads replies in Gmail and suggests tracker updates.
- It never applies on its own: I review and send every application myself.
- Built on top of the open-source [career-ops](https://github.com/santifer/career-ops) (MIT) by santifer; the server, scheduler, Telegram bot, panel and browser extension are mine.

`Node.js · OpenRouter (Claude, Gemini) · Telegram Bot API · Gmail API · VPS`
